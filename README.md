# Eduardo Machado - Portfolio

Portfolio profissional de Eduardo Machado, Analista de Dados.

## Sobre Mim

Analista de Dados com 15+ anos de experiência em tecnologia. Especialista em SQL, Python, Power BI e visualização de dados. Transformo dados em insights estratégicos para apoio à tomada de decisão.

## Stack

- HTML5 / CSS3 / JavaScript (ES6+)
- Tailwind CSS v3
- Formspree (formulário de contato)

## Estrutura

```
├── index.html              # Página principal do portfolio
├── bingo.html              # Jogo de Bingo (projeto auxiliar)
├── css/
│   ├── style.css           # Estilos customizados do portfolio
│   └── bingo.css           # Estilos do jogo de Bingo
├── scripts/
│   ├── main.js             # JavaScript principal do portfolio
│   └── bingo.js            # JavaScript do jogo de Bingo
├── media/
│   ├── 00de0bf3-fde6-4206-b6ca-7d73d3b613a7.jpg  # Foto de perfil
│   └── favicon.png         # Favicon do portfolio
├── maestro-bg.png          # Logo Maestro Sistemas
├── tailwind.config.js      # Configuração do Tailwind CSS
├── postcss.config.js       # Configuração do PostCSS
├── package.json            # Dependências do projeto
├── robots.txt              # Regras para crawlers
├── sitemap.xml             # Sitemap para SEO
└── manifest.json           # Manifest PWA
```

## Como rodar localmente

```bash
# Instalar dependências
npm install

# Iniciar desenvolvimento (observa alterações no CSS)
npm run dev

# Build para produção
npm run build
```

## Deploy

O site é publicado automaticamente via GitHub Pages a partir da branch `master`.
