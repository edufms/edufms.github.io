## Estrutura

```
├── index.html              # Pagina principal do portfolio
├── bingo.html              # Jogo de Bingo (projeto auxiliar)
├── css/
│   ├── style.css           # Estilos customizados do portfolio
│   └── bingo.css           # Estilos do jogo de Bingo
├── scripts/
│   ├── main.js             # JavaScript principal do portfolio
│   └── bingo.js            # JavaScript do jogo de Bingo
├── media/
│   ├── 00de0bf3-...jpg     # Foto de perfil
│   └── maestro-bg.png      # Logo Maestro Sistemas
├── tailwind.config.js      # Configuracao do Tailwind CSS
├── postcss.config.js       # Configuracao do PostCSS
├── package.json            # Dependencias do projeto
├── robots.txt              # Regras para crawlers
├── sitemap.xml             # Sitemap para SEO
└── manifest.json           # Manifest PWA
```

## Como rodar localmente

```bash
# Instalar dependencias
npm install

# Iniciar desenvolvimento (observa alteracoes no CSS)
npm run dev

# Build para producao
npm run build
```

## Deploy

O site e publicado automaticamente via GitHub Pages a partir da branch `master`.
